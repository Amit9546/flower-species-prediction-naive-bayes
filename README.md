# Flower Species Prediction using Naive Bayes

A machine learning project built with Python and Scikit-Learn that classifies iris flower species using the **Gaussian Naive Bayes** algorithm. The repository also includes exploratory data analysis and model evaluation using secondary datasets[cite: 1].

## 📋 Features

* **Data Loading & Preprocessing**: Loads the Iris dataset (`load_iris`) and features cleaning/formatting using Pandas and NumPy[cite: 1].
* **Machine Learning Model**: Implements `GaussianNB` from Scikit-Learn for supervised multi-class classification[cite: 1].
* **Model Evaluation**: Assesses model performance using confusion matrices, accuracy scores, and detailed classification reports[cite: 1].
* **Bonus Analysis**: Contains secondary experimental code leveraging diabetes datasets with Support Vector Classification (`SVC`)[cite: 1].

## 🛠️ Tech Stack

* **Python**[cite: 1]
* **Pandas & NumPy** (Data manipulation)[cite: 1]
* **Scikit-Learn** (Machine Learning models and metrics)[cite: 1]
